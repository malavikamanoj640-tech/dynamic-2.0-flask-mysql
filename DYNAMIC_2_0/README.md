# DYNAMIC 2.0 — Smart Student Productivity & Learning Workspace

DYNAMIC 2.0 is a full-stack student productivity and learning workspace built with **Python, Flask, MySQL, HTML, CSS, JavaScript and Bootstrap**. It brings study planning, task tracking, personal notes, focus sessions, quizzes and learning analytics into one application.

## Features

- **Dashboard:** task summaries, completion indicators, weekly focus activity and upcoming events.
- **Task management:** create, search, filter, complete and delete tasks with priority and due dates.
- **Knowledge workspace:** create and manage notes with categories, tags and review features.
- **Focus Zone:** Pomodoro-style focus timer with recorded study sessions and subject tracking.
- **Quiz Center:** topic-based quizzes covering Python, SQL/DBMS, web development and computer fundamentals.
- **Study planner:** calendar events with dates and categories.
- **Study goals:** set study-minute targets and review recorded progress.
- **Learning analytics:** weekly focus charts, quiz performance and recent activity.
- **Smart suggestions:** transparent rule-based guidance based on recorded tasks, quiz averages and focus time. These are not ML predictions.
- **CSV report:** export personal tasks, focus sessions and quiz attempts.
- **Profile and activity history:** review account details and recent workspace actions.
- **Admin console:** view aggregate counts and manage student/admin roles.

## Requirements

- Windows 10/11, macOS or Linux
- Python 3.10+
- MySQL 8+ or XAMPP MySQL/MariaDB
- Git (optional, for cloning)
- A modern browser

## Run locally (Windows + XAMPP)

1. Install Python and XAMPP.
2. Start **MySQL** from the XAMPP Control Panel. Apache is not required because Flask serves the application.
3. Clone the repository or extract the ZIP.
4. Open a terminal in the folder containing `app.py`.
5. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

6. Install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

7. Review `config.py`. Defaults match a typical local XAMPP setup (`localhost`, `root`, blank password, port `3306`, database `dynamic2_db`). For another setup, set the corresponding `DYNAMIC_MYSQL_*` environment variables.
8. Set a persistent secret key before starting the app:

   ```powershell
   $env:DYNAMIC_SECRET_KEY = "replace-this-with-a-long-random-secret"
   ```

   Use a long random value and never publish it. The fallback generated by `config.py` is for local development and changes on restart.
9. Start the application:

   ```powershell
   python app.py
   ```

10. Open `http://127.0.0.1:5000`, register and sign in.

## Database setup

On startup, the application connects to the configured MySQL server, creates the configured database if it does not exist, creates missing tables and applies supported column migrations. It does not drop or truncate existing user data.

The MySQL account must have permission to create databases and tables. If it does not, create `dynamic2_db` manually in phpMyAdmin and grant the application account appropriate access.

`database.sql` is provided for reference/manual setup. `upgrade_existing.sql` is retained for users maintaining an older schema. Back up important data before upgrades.

## Enable the admin console

1. Register the account that should receive administrator access.
2. Open phpMyAdmin, select `dynamic2_db`, choose the SQL tab and run the following query. Replace the email with the registered account's email:

   ```sql
   INSERT INTO user_roles (user_id, role)
   SELECT id, 'admin'
   FROM users
   WHERE email = 'your-admin-email@example.com'
   ON DUPLICATE KEY UPDATE role = 'admin';
   ```

3. Sign out and sign in again.

Only grant administrator access to accounts you trust.

## Configuration reference

| Variable | Purpose | Default |
|---|---|---|
| `DYNAMIC_SECRET_KEY` | Flask session signing key | Random development fallback |
| `DYNAMIC_MYSQL_HOST` | MySQL host | `localhost` |
| `DYNAMIC_MYSQL_USER` | MySQL username | `root` |
| `DYNAMIC_MYSQL_PASSWORD` | MySQL password | Empty |
| `DYNAMIC_MYSQL_DB` | Database name | `dynamic2_db` |
| `DYNAMIC_MYSQL_PORT` | MySQL port | `3306` |
| `DYNAMIC_DEBUG` | Flask debug mode | `false` |
| `DYNAMIC_HTTPS` | Secure session cookie flag | `false` |

## Security and privacy

- Passwords are stored using bcrypt hashing.
- Database access uses parameterized queries for user-provided values.
- Unsafe HTTP methods require a session-backed CSRF token.
- Do not commit secrets, local `.env` files, database dumps or real user records.
- For public deployment, use HTTPS, a persistent secret key, a restricted database account, rate limiting and a production WSGI server.
- Disable debug mode outside local development.

See [SECURITY.md](SECURITY.md) for additional notes.

## Known limitations

- Smart suggestions use explicit rule-based conditions; no trained machine-learning model is used.
- Analytics show only activity recorded in this application.
- The focus timer records completed sessions; refreshing or closing the page before completion interrupts the active timer.
- Bootstrap, Bootstrap Icons, Google Fonts and Chart.js are loaded from CDNs, so the interface requires internet access for those assets.
- The coding hub's browser-based preview supports HTML/CSS/JavaScript. Python execution uses Pyodide and requires internet access on first load. C/C++ examples are reference material and do not include a native compiler.
- This is an academic portfolio project, not a hosted commercial service.
